Odoo Inventory

Product Attribute Variant Stock Guard

Prevents product attribute value deletion when linked variants still have on-hand or reserved stock in internal inventory locations.

Overview

This module adds a stock safety check when deleting product template attribute values. If a related product variant has quantity or reserved quantity in an internal location, Odoo blocks the deletion and shows a user-facing warning.

Key Features

Attribute value deletion guard

Checks variants linked to the product template attribute value before allowing deletion.

On-hand stock protection

Blocks deletion when linked variants have positive quantity in internal stock locations.

Reserved stock protection

Blocks deletion when linked variants have reserved quantity in internal stock locations.

Standard Odoo warning

Uses an Odoo user error to explain that the variant cannot be deleted because it has inventory stock.

How It Works

  1. A user attempts to delete a product template attribute value.
  2. The module checks the product variants linked to that attribute value.
  3. It searches internal inventory locations for positive on-hand quantity or reserved quantity.
  4. If stock is found, deletion is stopped with a clear warning message.
  5. If no linked variant stock is found, Odoo continues with the normal deletion flow.

Benefits

  • Helps prevent accidental variant deletion while inventory still exists.
  • Protects stock consistency for products using attributes and variants.
  • Adds the check without adding menus, configuration screens, or new workflows.
